# Praxis brand — quick reference

Canonical source: [`BRAND_GUIDE.html`](BRAND_GUIDE.html) (Brand Guidelines v1.0). This file is the
working summary; when in doubt, the guide wins.

> These assets brand **Praxis itself** — the baseline repo, its README, docs site, and marketing.
> They are deliberately kept out of `bootstrap.sh init`: projects built *on* Praxis carry their own
> brand, never this one.

## The mark

Π — the Greek capital Pi. Two uprights and a lintel: a gate. The threshold theory crosses to become
action. The **right leg carries the terracotta accent** — never both legs, never the left. The
negative space is a doorway; keep it open.

| File | Use |
|---|---|
| `mark-light.svg` | Mark only, on paper/light grounds. App icon, favicon, bullets. |
| `mark-dark.svg` | Mark only, reversed for ink/dark grounds. |
| `lockup-light.svg` | Mark + wordmark + tagline, light grounds. |
| `lockup-dark.svg` | Mark + wordmark + tagline, dark grounds. |

Minimum size 16px. Clear space = the height of the lintel, all sides. Never stretch, rotate,
recolor outside the palette, add effects, or reset the wordmark font.

## Color

| Token | Hex | Role |
|---|---|---|
| Ink | `#1A1714` | Text, mark |
| Ink 2 | `#3A352E` | Body copy |
| Stone | `#8A8174` | Captions, secondary |
| Line | `#D8D0BF` | Rules, borders |
| Panel | `#ECE6D9` | Fills |
| Paper | `#F3EFE6` | Ground |
| **Terracotta** | `#B85C38` | Primary accent — *action*. The live leg, links, the one button that matters. |
| Ochre | `#C2912F` | Secondary — state and status: KPIs, badges, "in progress". |

Usage ratio ≈ Paper 62 / Ink 28 / Terracotta 7 / Ochre 3. Keep accent under ~10% of any surface.

## Type

- **Spectral** (serif) — display and editorial. The voice.
- **Space Grotesk** — wordmark (Semibold, tracked +0.04em) and interface.
- **JetBrains Mono** — code, state, eyebrows, KPIs. The record.

## Voice

Authoritative, precise, a little classical. Short sentences. Earned confidence. Never hype
("revolutionary", "10x"), never emoji-laden, never vague, never apologetic.

Taglines:
- **Theory, compiled into action.** (primary)
- Discipline, by design.
- If it isn't written, it didn't happen.
- The AI-native operating system for disciplined building. (descriptor)
- Build well. Repeatedly. (the eupraxia line)
- State that survives every reset.
